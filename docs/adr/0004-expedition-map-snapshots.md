# Expedition snapshots preserve history without locking Maps

**Status:** Accepted

An Opportunity Map is a living atlas for one team or area. It remains editable throughout its life. Confirming an Expedition captures an immutable Map snapshot rather than setting the Map read-only or creating a manual Map version.

An Expedition is a focused, evidence-seeking team commitment: it selects prepared Islands and records an Island Charter for each selected Island rather than a generic Expedition mission. It does not repeat Island discovery or evaluation; an Island owns the opportunity hypothesis and its value evidence. Island evaluation values remain authored on the Map. A required planning horizon and team-controlled, explainable Expedition lens apply weights to those existing values and the Workspace strategy to suggest a focus order. Only one Expedition is active per Map; starting another makes the prior one past.

This preserves historical context and makes later Map changes comparable to an Expedition's snapshot without a mandatory change note or an Iteration lifecycle. The snapshot includes the planning horizon, applied Expedition lens, Island values used, suggested focus order, final order, and any override rationale. The comparison distinguishes post-confirmation personal Scouting notes from newly charted Islands and shows evaluation value movement explicitly. If the current Map values newly make an unselected Island stronger than a selected Island, it presents a read-only notice only; it neither changes nor replaces the Expedition.
